## 실행 코드에서 확인한 주의점

- `./lekiwi scene`은 색상 코스의 키보드 주행입니다.
- `./lekiwi teleop --port ... --id ... --scene random`은 리더 + 베이스이며, `--record`를 추가하면 같은 환경에서 기록합니다.
- 기록 공통 코드는 기존 경로 `isaacsim_basic/06_lekiwi_dataset/experiments/01_lekiwi_recording.py`에 유지합니다.
  `LEKIWI_RECORD_TASK`·`LEKIWI_RECORD_SECONDS`가 코드 기본값보다 우선합니다.
- 학생 experiments 파일은 저장 후 재실행에 반영됩니다.
  `isaac_sim/keyboard_drive.py` 같은 공통 코드를 바꾸면 `./lekiwi setup sim`이 필요합니다.
- `02_dataset_list.py`부터 `07_infer_act.py`는 호스트에서 실행하며, 내부 실행기가 Docker 환경을 사용합니다.

## 환경 오류 처리 이력

처음에는 NVIDIA 580.178.04 DKMS가 설치됐지만 MOK 미등록으로 드라이버를 읽지 못했습니다.
MOK 등록 후 사용자 로그에서 RTX 4060과 드라이버가 인식됐고 Docker·Container Toolkit 설치로 진행했습니다.
이후 이미지 빌드는 `pypi.nvidia.com`의 CUDA 의존 파일 다운로드 중 읽기 시간 초과로 중단됐습니다.
사용자가 이 문제를 해결했다고 알리고 교재 재개를 요청했습니다. 이번 교재 수정에서는 설치 코드·드라이버를 변경하지 않았습니다.
사용자의 해결 보고와 대여 노트북 전체 설치·렌더링·수업 검증을 구분합니다.
