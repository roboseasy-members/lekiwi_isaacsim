# Isaac Sim · 환경 설정부터 텔레옵·데이터·ACT까지

**0장 환경 설정 → 1~3장 물리·관절·카메라 → 4장 텔레옵 → 5장 데이터 취득 → 6장 변환·학습·추론** 순서입니다.
학생별 Ubuntu NVIDIA GPU 노트북 한 대를 사용하며 SO101 리더 USB도 같은 노트북에 연결합니다.
처음이라면 [0장 환경 설정](00_env_setting/README.md)부터 읽습니다.

1~3장은 **화면에서 직접 만들고 관찰한 뒤 같은 원리를 코드로 확인**합니다.
4장부터는 기존 **빨강·주황·노랑·초록 코스**를 사용합니다. 키보드로 베이스, 리더암으로 팔·집게를 조작한 뒤 그 시연을 저장해 학습합니다.
각 장의 README 한 문서를 순서대로 읽으면 실행 위치·수정할 파일·설정·명령·완료 기준을 확인할 수 있습니다.

코드가 처음이면 [experiments 코드 읽기](CODE_GUIDE.md)에서 파일별 실행 명령·함수 역할·값을 바꾸는 방법을 함께 확인하세요. 각 Python 파일 맨 위에도 해당 실험의 설명이 있습니다.

## 어디에서 무엇을 실행하는가

모든 명령은 **같은 노트북의 저장소 최상위 폴더**, 즉 `ls lekiwi`가 파일을 찾는 터미널에서 입력합니다.

| 단계 | 실행 방법 |
|---|---|
| 1~3장 마우스 실습 | `./lekiwi basic --script 01_object_physics/experiments/00_empty_stage.py` |
| 1~3장 마지막 코드 확인 | `./lekiwi basic --chapter 1`, `2`, `3` 중 해당 번호 |
| 4장 키보드 코스 연습 | `./lekiwi scene` |
| 4장 리더 + 베이스 | 4장에 있는 `./lekiwi teleop --port ... --id ... --scene random` |
| 5장 실제 시연 저장 | 4장의 teleop 명령에 `--record` 추가. 5장의 과제·시간 설정 사용 |
| 5장 리더 없이 기록 검사 | `./lekiwi record` |
| 6장 변환·학습·추론 | 6장의 `02_dataset_list.py`~`07_infer_act.py`를 호스트 `python3`로 실행 |

`--port ...`는 실행 가능한 완성 명령이 아니라 본인 장치 경로를 넣어야 하는 설명입니다. 각 장의 전체 명령을 따릅니다.
기존 실행을 종료한 뒤 다음 명령을 사용합니다. 기록은 저장·폐기를 마친 뒤 종료합니다.
`./lekiwi classroom` 선택 창은 1~3장 코드, 4장 키보드 코스, 5장 키보드 기록 검사, 6장 데이터 목록을 엽니다.
리더 연결·변환·학습·추론은 안전 확인과 설정 수정이 있으므로 교재의 터미널 절차를 따릅니다.

### 1~3장 직접 만든 장면과 보충 예제

1장의 `base_scene.usda`를 2·3장의 시작 장면으로 사용합니다.
직접 제작한 파일은 `/data/isaacsim_basic/`에 새 이름으로 저장합니다. 호스트에서는 저장소의 `data/isaacsim_basic/`입니다.
1장의 실험 번호 `--experiment 1`~`6`은 장 번호와 다릅니다.

기존 `basic --chapter 4`는 단일 관절 J/L/K 입력, `--chapter 5`는 단일 관절 JSON 기록·재생 보충 예제입니다.
`--chapter 6`은 키보드 LeKiwi 기록 예제입니다. 이 명령들은 보관하지만 현재 4~6장 본 수업 순서는 위 표를 따릅니다.
4~6장의 코스 실습에 `my_joint.usda`나 직접 만든 바구니 USD가 필요하지 않습니다.

## 파일을 수정한 뒤 반영하는 방법

1. 실행 중인 작업을 저장·종료합니다.
2. VS Code에서 교재에 명시된 파일을 열고 설정을 바꿉니다.
3. Ctrl+S로 저장합니다.
4. 해당 장의 실행 명령으로 다시 시작하고 결과를 확인합니다.

`isaacsim_basic/*/experiments/*.py` 학생 파일은 저장 후 재실행하면 반영됩니다.
4장의 선택 실습처럼 `isaac_sim/keyboard_drive.py` 공통 코드를 바꾸면 `./lekiwi setup sim`으로 이미지 갱신이 필요합니다.
GUI에서 USD를 저장해도 Python 파일이 자동 수정되지는 않습니다.

1~3장 Isaac Sim 학생 파일은 `./lekiwi basic ...`으로 실행합니다. 호스트 Python으로 직접 실행하면 `omni`·`pxr`를 찾지 못할 수 있습니다.
6장 목록·변환·검사·업로드·학습·추론 파일은 **호스트 `python3`가 Docker 실행기를 호출**하는 구조입니다.
저장된 시연·변환본·학습 결과·보정은 `data/`에 남으며 컨테이너 종료 후에도 유지됩니다.
