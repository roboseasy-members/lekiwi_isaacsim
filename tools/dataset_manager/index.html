시연에서 데이터셋까지

이 PC에 저장한 시연을 확인하고, 로컬 학습에 사용할 데이터셋을 준비하세요.

연결 중…

1. 완료된 시연 선택

미리보기는 첫 프레임입니다. 작업 성공 여부는 전체 시연을 검토해 기록한 표시를 따릅니다.

2. 로컬 데이터셋으로 변환

원본 시연은 보존하고 새 데이터셋 폴더에 저장합니다.

3. 학습 전 데이터 확인

프레임 수와 관절·카메라 규격, 처음·중간·마지막의 상태와 영상을 확인합니다.

다음 과정에서는 이 로컬 데이터로 ACT를 학습하고, 저장한 모델로 Isaac Sim 추론을 진행합니다. 학습·추론 화면은 아직 준비 중입니다.

작업 결과

아직 실행한 작업이 없습니다.
